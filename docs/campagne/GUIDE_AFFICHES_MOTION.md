# Hello World — Guide affiches & motion design (campagne CADEV)

Objectif : faire connaître **Hello World** comme un vrai produit, pas comme un « projet de concours ».
Le vote n'arrive qu'en fin de parcours : on donne d'abord envie, ensuite on demande le soutien.

## 2. Le message, en une phrase

> **Hello World — le réseau social des bâtisseurs.** Partage ce que tu codes, trouve ton équipe, fais-toi repérer en Afrique.

Trois idées à faire passer, une par affiche :
1. **Partager** : « Montre ce que tu codes. » (publications avec du code coloré)
2. **S'entraider** : « Ton bug a déjà une réponse. » (questions techniques, réponses utiles)
3. **Construire ensemble** : « Trouve ton équipe. » (projets ouverts aux débutants, tâches, messagerie d'équipe)

## 3. Identité visuelle (reprendre l'app, rien inventer)

**Couleurs**
- Fond : `#141414` · Surface : `#202020` · Bordures : `#373737`
- Texte : `#FFFFFF` · Texte secondaire : `#B8B8C0`
- Accent violet : `#B794FF` · Vert « code / succès » : `#7EE787` · Étoile : `#F59E0B`
- Pas de dégradés ni d'effets arc-en-ciel : des aplats de couleur, c'est plus pro.

**Typographies (Google Fonts, gratuites)**
- **Inter** Bold pour les titres, Regular pour le texte.
- **Geist Mono** pour la marque `Hello World>_`, les `@pseudos`, le code et les tags.

**Signes de la marque**
- Le curseur `>_` (qui clignote en motion).
- Les lignes de terminal : `$ hello-world join`
- Un bloc de code sobre, fond sombre, police Geist Mono (comme dans l'app).

**Règles de propreté**
- 1 message par affiche, 7 mots maximum pour le titre.
- Marges larges : au moins 8 % de la largeur sur chaque bord.
- 3 couleurs maximum par visuel (fond sombre + blanc + un accent).
- Toujours le logo et l'URL **hello-world.ci** en bas.
- Captures d'écran **réelles** de l'app, dans un cadre de téléphone (mockup).

## 6. Motion design (vidéo de 15 à 20 s, 1080 × 1920)

| Temps | Image | Texte / son |
| :--- | :--- | :--- |
| 0–2 s | Écran noir, une ligne s'écrit : `$ hello-world` puis le curseur `>_` clignote | Bruit de clavier |
| 2–5 s | Le logo grossit sur fond noir uni | « Le réseau social des bâtisseurs » |
| 5–8 s | Le téléphone glisse, on fait défiler le fil (capture réelle) | « Partage ce que tu codes » |
| 8–11 s | Zoom sur une question et sa réponse en code | « Trouve de l'aide » |
| 11–14 s | Page Projets, badge vert qui « pop » | « Trouve ton équipe » |
| 14–18 s | Fond noir, logo + `hello-world.ci` + « Votez pour nous à la CADEV » | Musique qui monte puis s'arrête net |

Conseils d'animation :
- Courbe d'accélération douce (ease-out) et mouvements courts de 300 à 500 ms.
- Une seule chose bouge à la fois.
- Texte affiché au moins 1,5 s pour qu'on ait le temps de le lire.
- Sous-titres toujours présents : la plupart des gens regardent sans le son.

Outils : **After Effects** (le plus propre), **CapCut** (rapide, modèles), **Canva** (affiches et petites animations), **Figma** pour les maquettes.

## 8. Plan de diffusion pendant les 2 jours de vote

- **8 h** : affiche « Appel au vote » + lien, dans tous les groupes WhatsApp (promo, université, famille, communautés tech).
- **12 h** : la vidéo de motion design (statuts, TikTok, Reels).
- **18 h** : rappel avec une affiche « fonctionnalité » (2, 3 ou 4).
- **21 h** le 20 nov. : « Dernières heures » avec un compte à rebours.
- Chaque membre de l'équipe partage depuis **son propre compte** et demande à 10 personnes en message privé (c'est ce qui convertit le mieux).

## 9. Checklist avant de publier

- [ ] Le lien de vote est le bon et s'ouvre sur téléphone.
- [ ] `hello-world.ci` est lisible sur l'affiche.
- [ ] Les captures d'écran viennent de l'app réelle, à jour, sans données privées.
- [ ] Le QR code a été scanné et testé.
- [ ] Aucune faute (faire relire par une autre personne).
- [ ] Le logo Systalink / CADEV est utilisé seulement si le règlement l'autorise.
